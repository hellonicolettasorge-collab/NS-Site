# nicolettasorge.com

Sito single-page di Nicoletta Sorge, copywriter e content strategist.

Stack: React 19, Vite, Tailwind CSS 4, Motion.

## Sviluppo

Richiede Node.js.

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # type-check con tsc
npm run build    # output in dist/
```
